Anubis

AI-native version control.
Semantic commits and reasoning traces on top of git.

pip install anubis-vcs
View on GitHub PyPI Package

The Problem

AI coding sessions end and context is lost
You can't resume exactly where you left off
No record of the reasoning behind changes
Code review lacks the "why"

The Solution

Checkpoints with Reasoning

Save not just code state, but why you made changes. "Trying JWT approach because sessions don't scale."

File Snapshots

Capture content and diffs at each checkpoint. Full context preserved.

Semantic Analysis

Automatically detect what changed: added functions, renamed classes, modified signatures.

AI-Friendly Output

Export checkpoints in a format perfect for pasting into Claude, ChatGPT, or Cursor.

Quick Start

# Initialize in any git repo
anubis init

# Create checkpoint with reasoning
anubis checkpoint "Refactoring auth" -r "Trying JWT, sessions don't scale"

# View history
anubis log

# Resume with AI-optimized output
anubis resume abc123 --format=prompt

# See semantic analysis
anubis analyze

Claude Code Integration

Auto-checkpoint when Claude makes changes to your code.

anubis hooks setup
# Add output to ~/.claude/settings.json
